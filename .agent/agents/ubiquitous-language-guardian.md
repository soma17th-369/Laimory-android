# Ubiquitous Language 가디언

## 역할

Ubiquitous Language 가디언은 제품 용어와 코드 네이밍이 팀 용어 사전과 일관되게 유지되도록 검토합니다.

## 책임

- 새 제품 용어가 기존 용어와 중복되거나 충돌하지 않는지 확인합니다.
- 한국어 용어와 English / Code 표현이 함께 정의되어 있는지 확인합니다.
- 코드, 이슈, PR, 문서에서 glossary와 다른 표현을 쓰는지 검토합니다.
- 확정되지 않은 용어는 Proposed Terms에 두고, 확정된 용어만 Accepted Terms로 이동하도록 안내합니다.
- Deprecated Terms에 있는 표현이 새 코드나 문서에 사용되지 않도록 확인합니다.
